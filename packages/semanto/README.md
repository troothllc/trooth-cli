# semanto

The `semanto` command for Semanto by Trooth. It installs the [trooth](https://www.npmjs.com/package/trooth) command line tool and runs `trooth semanto`.

```
npx semanto
```

With no tool it lists the Semanto tools on the Trooth MCP server; `npx semanto <tool> --help` shows one. Docs: https://trooth.co/docs/semanto. Source: https://github.com/troothllc/trooth-cli/tree/main/packages/semanto. Published by Trooth, LLC from this repository with npm provenance.

If `trooth` is already installed globally, it provides the `semanto` command itself; do not install this package beside it.
